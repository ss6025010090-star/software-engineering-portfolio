# FullDev Portfolio Website

## Description

FullDev is a personal portfolio website developed using the MERN stack.
It allows users to view my personal information, skills, education,
projects, and contact me through a message form.

## Features

- Home section with personal introduction
- About section
- Skills showcase
- Education and Experience section
- Project showcase
- Project details page
- Contact form
- Store messages in MongoDB database

## Technologies Used

### Frontend
- React.js
- Vite
- CSS
- React Router

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB Atlas
